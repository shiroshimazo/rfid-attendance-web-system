## Local seed

## Schedule rule

The approved rule is unchanged: select the active all-campus row first, otherwise the matching active campus-specific row. Late is strictly after start plus grace; equality stays Present. No schedule or non-pilot placement does not infer Late. Subject Present/Late/Absent remains teacher-confirmed and separate.

## Historical review

The existing `supabase/backfill_late_status.sql` filename now contains only a SELECT. Running the entire file does not update any records. Returned rows are candidates, not confirmed errors: the current section or schedule may differ from the original date. A recorded-campus/current-campus mismatch is visible for review.

If a historical correction is needed later:

1. Review the specific returned IDs against the original placement and rule on that date.
2. Preserve complete before-images for those records.
3. Prepare an explicit transaction limited to approved IDs, with unchanged-status/timestamp checks so stale review results cannot overwrite newer edits.
4. Verify affected-row count and preserved unrelated history before committing. Restore from before-images only after checking for subsequent changes if rollback is required.

No historical mutation script is enabled by P10, and no historical rows were changed. Reverting repository edits does not require a database rollback because no migration or hosted mutation was performed.
